## About me

I'm an AI engineer focused on turning models into practical applications. My work brings together agent workflows, backend APIs, and full-stack product development.

I enjoy the early stages of building: understanding a problem, getting a working version into someone's hands, and improving it through feedback. I'm especially interested in small teams where I can own a feature across the model, API, interface, and deployment.

- 🤖 **AI applications:** multi-agent systems, tool calling, structured outputs, and workflow orchestration.
- 🛠️ **Product engineering:** Python backends, TypeScript interfaces, and integrations that connect the pieces.
- 🔭 **Currently building:** Orchestra AI, an open-source developer control plane.
- 🌱 **Exploring:** how to make agent workflows easier to inspect, evaluate, and operate.

## Selected projects

### 🎼 [Orchestra AI](https://github.com/VarunTx/orchestra-ai)

An open-source, self-hostable control plane for managing the projects you build.

- Brings projects, environments, services, health checks, and incidents into one dashboard.
- Uses Conductor OSS for durable workflows, with execution history, task inspection, and retry controls.
- Connects a Next.js interface to a FastAPI backend and PostgreSQL, with optional Gemini-assisted incident analysis.

**Built with:** Python · FastAPI · TypeScript · Next.js · PostgreSQL · Conductor OSS · Docker

[View repository →](https://github.com/VarunTx/orchestra-ai)

### 🌻 [Sunflower Grove — AI Front Desk](https://github.com/VarunTx/aws_hackathon)

A hackathon project that turns a fictional preschool's front desk into a coordinated team of six AI agents.

- Routes parent questions to specialist agents using the Agent2Agent (A2A) protocol.
- Combines model-generated responses with decisions made by rules in code and citations to approved policies.
- Includes a parent chat, an operator dashboard, and a human approval flow for policy updates.

**Focus:** Multi-agent coordination · Tool calling · Cited responses · Human-in-the-loop workflows

[View repository →](https://github.com/VarunTx/aws_hackathon)
