# Varun Talari
### AI engineer. Product builder.

I like taking an open-ended problem and turning it into a working product. I work across AI behavior, application development, and infrastructure—making the decisions, connecting the pieces, and following through on deployment.

For me, shipping includes understanding how the system behaves once it runs: evaluating its answers, tracing failures, and making it easier to improve. That’s the thread connecting the projects below.

### Selected work

**[HarnessOps](https://github.com/VarunTx/harness-ops) · Building agents that learn from human feedback**  
A support agent that turns corrections into versioned memory and proposes reviewable changes to its own instructions. Built the agent, review interface, and evaluation loop; results improved from **3/14 to 14/14** on a small development benchmark. [Read the case study →](https://github.com/VarunTx/harness-ops/blob/main/docs/CASE_STUDY.md)

**[Orchestra AI](https://github.com/VarunTx/orchestra-ai) · Giving independent builders an operations dashboard**  
An open-source control plane for managing projects, running durable workflows, and tracking service health. Brings the product interface, backend, monitoring, incident handling, and self-hosted deployment into one system.

**[Sunflower Grove](https://github.com/VarunTx/aws_hackathon) · Taking a multi-agent idea into a usable application**  
A hackathon project with six specialist agents, a parent-facing chat, and an operator dashboard. Connects agent coordination with policy-cited answers and human approval of policy changes.
